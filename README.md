# omicron-channel

Omicron-Channel PRO: construcción de cauces trapezoidales sobre un MDT a partir de un eje, con perfil de rasante por puntos de control y cálculo de desmonte. Compatible con QGIS 3.44 y QGIS 4 (Qt6).

## Instalación

Descarga el ZIP del plugin desde [Releases](https://github.com/jrbarrientosGIS/CHANNEL/releases/latest) y en QGIS: *Complementos → Administrar e instalar complementos → Instalar a partir de ZIP*.

> El botón "Download ZIP" del repositorio **no** sirve para instalar directamente: el plugin está en la subcarpeta `omicron_channel/`.

## Versiones anteriores

La versión para QGIS 3 (5.4.9) está disponible en [Releases](https://github.com/jrbarrientosGIS/CHANNEL/releases).
