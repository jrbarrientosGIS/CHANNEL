# omicron-channel

Omicron-Channel PRO: construcción de cauces trapezoidales sobre un MDT a partir de un eje, con perfil de rasante por puntos de control y cálculo de desmonte. Compatible con QGIS 3.44 y QGIS 4 (Qt6).

## Instalación

Descarga el ZIP del repositorio (o de Releases), y en QGIS: *Complementos → Administrar e instalar complementos → Instalar a partir de ZIP*.
